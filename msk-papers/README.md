- `肌骨康复图文论文清单.csv`：同一张表的 CSV 版本（UTF-8 带 BOM，Excel 直接打开不乱码）

收录范围：肌骨影像、解剖、骨科（含体格检查与骨折）、骨科石膏固定、手法复位、关节注射、骨科康复、康复治疗、物理治疗、运动康复、运动训练。

筛选规则：
- 全部 340 篇均为开放获取（PubMed Central 全文），表中有 PDF 下载链接与许可证列（CC BY 143、CC BY-NC 70、CC BY-NC-ND 87、CC BY-NC-SA 17、出版商开放获取 23）
- 逐篇读取全文 XML，统计图片数量并阅读图注；图数 ≥ 5，187 篇 ≥ 10，合计 4283 幅图
