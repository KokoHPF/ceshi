# 论文 → 小红书图文卡片

这份说明不依赖任何特定模型或平台：只要能运行 Python 3、能看图片（用来检查成品），就能按步骤完成。
脚本都在 `scripts/`，默认主题在 `config/theme.default.json`，完整示例在 `examples/thumb_test/`。

## 0. 环境准备（第一次）

```bash
pip install pillow pymupdf numpy matplotlib opencv-python-headless rapidocr_onnxruntime
bash scripts/setup_fonts.sh          # 下载思源黑体到 fonts/（约 34 MB）
# 截视频帧还需要 ffmpeg
```

## 1. 默认设置与可调整项

默认值写在 `config/theme.default.json`：账号名“**骨科康复小黄**”、深蓝 / 珊瑚橙 / 亮黄配色、米白底、思源黑体、1080×1440、单篇最多 18 张。

要改的话新建一个 JSON，只写要改的字段，然后传给 `Deck(..., theme='my_theme.json')`，例如：

```json
{"account": "某某康复", "colors": {"primary": "#1F3A5F", "accent": "#E4572E"}, "cover_tag": "干货收藏"}
```

用户在对话里提出的改动（换账号名、换配色、改张数上限、封面标签等）一律用这种方式覆盖。**不要改默认文件**，除非用户明确要求改默认值。

## 2. 工作流程（按顺序做，每步都要看结果）

### 2.1 读论文，先做三件事

1. **查重**：如果有历史作品目录，确认这篇以前没做过；做过就先告诉用户。
2. **查版权**（看首页页脚、PubMed/PMC 的许可信息）：
   - CC BY：可直接用。
   - 带 **NC**（非商业）、**ND**（禁止演绎）、**SA**，或没有标注开放许可：**要先提醒用户**。最后一页写明许可，并加“仅供学习交流，如有侵权请联系删除”。
   - 把图中英文改成中文，在 ND 协议下严格说也算演绎，要一并提醒。
3. **通读全文**：记下每张图对应的检查或动作、表格内容、关键数字。顺手找出原文里**前后矛盾或明显错误的地方**（数字算不对、图号错位、引用错位、正文与表格不一致），在卡片上注明“原文如此”，回复用户时一并列出。

### 2.2 提取图片

```bash
python3 scripts/extract_figures.py paper.pdf work/
```

- 看 `work/_thumbs.jpg` 和 `work/page*.png`，把每张图和图注（`figures.json` 里有页码和位置）对上号。
- **箭头、标签是 PDF 矢量叠加层**（提取出的原图上看不到）或**提取出来是反色**时，改用整页区域渲染：
  `python3 scripts/extract_figures.py paper.pdf work/ --clip 页码(从0起) x0 y0 x1 y1 名称`，坐标取自 `figures.json` 里的 bbox。
- 左右拼在一起的多幅图，用 `cardkit.split_lr(img)` 切开，竖版里上下或分开放更大。
- **全部原图都要用上**，不要漏图。照片**不要模糊、不要遮挡**，保持原比例。

### 2.3 配套视频（有就做）

- 正文里提到 “Video 1 / Supplementary Video” 时：
  `python3 scripts/fetch_supplement.py <DOI> work/supp`。期刊网站大多会返回 403，这个脚本走 Europe PMC，往往能拿到视频和高清原图（gr*.jpg）。
- 截帧：
  - 先 `python3 scripts/video_frames.py work/supp/mmc1.mp4 work --sheet 3` 看总览；
  - 再 `--at 22 25 53 --crop-black` 截取要用的时间点。竖屏视频加 `--crop-black` 去掉两侧黑边。
- 截帧用于补齐**原文没有配图的检查**，或做“第一步 / 第二步”的步骤图。

### 2.4 图里的英文 → 中文（重点）

- **照片或超声 / 磁共振图上有英文标注**（如 Examiner、Patient、肌肉缩写、方向词），用 `scripts/relabel.py` 三步走：
  1. `ocr`：OCR 定位文字。
  2. `preview`：生成核对图，红框表示词典里没有的词。补齐 `labels.json` 词典，漏检的框写进 `fixes.json`。
  3. `apply`：抹掉英文，补出背景纹理，再在原位写中文。
  - 格式见脚本开头的注释。缩写区分大小写（例如 Rm 是小菱形肌，RM 是大菱形肌）；长名称被拆成两行时会自动合并。
- **示意图本身没有文字**（解剖线条图、横断面示意）：用 `scripts/annotate.py` 给关键结构加中文标签、引线和方向（前 / 后、上 / 下），让读者看懂图在讲什么。
- **改完必须逐张看图**，重点看：
  - 有没有英文残留；
  - 中文有没有压住结构或箭头；
  - 单个字母的标注（M、F、LD 等）有没有被漏掉；
  - 相邻标注有没有重叠，重叠就用 `pos` 挪开。
- 原文标注含义不明时（例如图注没解释的缩写），按位置推断并加 `*`，在最后的回复里请用户确认。

### 2.5 规划卡片（11～18 张）

| 顺序 | 卡片 | 用什么 |
|---|---|---|
| 1 | 封面：大字标题用**论文标题的中文直译**（按语义切成 2～3 行）；1～3 张最有代表性的图；底部黄条写亮点 | `deck.cover` |
| 2 | 为什么重要 / 背景（流行率、难点、查体前准备） | `deck.text` 或 `deck.chart` |
| 3… | **每个检查、动作或示意图一张**：图 + 怎么做（步骤）+ 阳性或意义（信息框） | `deck.figure` |
| … | 原文没配图的检查：文字步骤卡；几个相关的小检查可以合并成一张 | `deck.text` |
| … | 原文表格：翻成中文，做成速查卡 | `deck.rows` |
| … | 准确性或疗效数据：重画成中文柱状图 | `deck.chart` |
| 倒数第 2 | 证据等级与局限 / 原文里对不上的地方 | `deck.text` |
| 最后 | 收藏页：一张图记住流程 + 文献 + 版权 | `deck.text` |

- **超过 18 张就拆成上、中、下篇**，每篇都要有自己的封面和“先学会看这些图”之类的导读。
- **写法要求**：
  - 详略得当，一张卡只讲一件事；
  - 步骤用动词开头；
  - 关键数字和结论用 `**加粗**`；
  - 不写原文没有的内容；
  - 专业名词用中文，必要时括号附英文缩写。

### 2.6 写构建脚本并生成

参照 `examples/thumb_test/build.py`：

```python
from cardkit import Deck
deck = Deck(series='栏目名(4～6字)', source='第一作者 等 期刊缩写 年;卷(期):页')   # 可加 theme=
deck.cover([...], kicker='期刊 年份', subtitle='一句话亮点', photos=[(img, '标签'), ...], banner='底部黄条')
deck.figure('标题', '原文图 X：说明', [img1, img2], ['标签1', '标签2'], items=[...])
deck.text('标题', '副标题', items=[...])
deck.rows('速查表', '原文表 1', [('行标题', '说明', '结论', 'teal'), ...], note='*注')
deck.chart('标题', '副标题', matplotlib_fig, items=[...])
deck.save('out/')
```

- **字号、图片高度、行距全部自动计算**：图片会尽量放大，文字取能放下的最大字号，空余处自动加大行距。
- 写 `items` 时**不要手动调字号或坐标**。放不下时脚本会报错，说明这张卡塞多了，应删减文字或拆成两张。
- 数据图用 matplotlib 画，中文字体用 `deck._fontfile['M']` 注册；figsize 宽 9.6、dpi 100 正好铺满 960 像素版心，字号建议 ≥18。
- `items` 格式见 `scripts/cardkit.py` 开头的说明。

### 2.7 质检（必须做，不能跳过）

打开 `out/_overview.jpg`，再抽看单张原图，逐项检查：

- [ ] 没有文字溢出版心、压到页脚、互相重叠；标题没有出框；
- [ ] 没有大片空白（图片小、文字少时，加内容、放大图或合并卡片）；
- [ ] 图片里没有残留英文，中文标注位置正确、没挡住结构；
- [ ] 数字没被拆行（“100%” 不能断成两行，引擎已处理，仍要看一眼）；
- [ ] 页码连续，总张数 ≤18；
- [ ] 封面标题就是论文标题的中文译文，账号名、来源、版权都正确。

发现问题就改 `build.py` 或素材，然后重新生成，直到全部通过。

### 2.8 交付

- `python3 scripts/pack.py 名称.zip 文件夹名=out/`（分篇时传多组）。
- 把卡片图片和 zip 发给用户，回复时说明以下内容：
  - 共几张，每张讲什么（可用表格）；
  - 图片做了哪些处理：哪些改了中文、哪些加了标注、哪些来自视频截帧；
  - 版权提醒（如有）；
  - 原文里对不上的地方；需要用户确认的推断；
  - 拿不到的东西（例如视频下载被拒）要如实说明。

## 3. 常见坑

- **期刊网站下载补充材料 403**：用 `fetch_supplement.py` 走 Europe PMC。没有 PMC 全文时，告诉用户需要手动下载。
- **提取出的图是反色，或丢了箭头**：用 `--clip` 按页面渲染。
- **OCR 漏掉单个字母或竖排字**：在 `fixes.json` 的 `extra` 里手动补框，竖排框会自动按竖排写。
- **原图分辨率低**（宽 <500 像素）：卡片上会发软，可以在回复里提一句。不要用 AI 放大“补细节”。
- **一张卡塞两个检查、文字太多**：拆成两张。总数超了就分篇。
- **字体缺字**（•、上标等显示成方块）：改用“·”、“*”等常见符号。
